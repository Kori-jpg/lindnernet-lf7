# LindnerNet – Lernfeld 7

Lern-Intranet der Lindner Bürowelt am Main KG (Modellunternehmen für den Unterricht, Kaufleute für Büromanagement, Lernfeld 7). Alle Namen, Personen und Daten sind frei erfunden.

- Statische Seite für GitHub Pages, ohne Konten, ohne Tracking, ohne Schülerdaten. Der Lernstand bleibt im Browser des Geräts.
- Die Inhalte liegen nur verschlüsselt in `content/*.enc.json` (AES-256-GCM). Anmeldung mit Kürzel und Code der Stunde; jeder Code öffnet ein eigenes Fach mit dem Schlüssel. Klartext-Inhalte und Codes gehören nicht in dieses Repository.
